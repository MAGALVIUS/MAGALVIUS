🔭 What I'm working on
Janus / Overlay — an offline OCR engine for archaeological paperwork. Java (Spring Boot, hexagonal architecture) orchestrates a Python PaddleOCR worker; handwritten fields go to Claude, printed text stays local. Turns scanned find lists and excavation forms into structured Excel, JSON and TXT.
Nexus — a desktop app for managing documentation projects and workflows. Tauri + React + TypeScript on the front, Spring Boot + H2 + Flyway behind, built with DDD across four bounded contexts.
